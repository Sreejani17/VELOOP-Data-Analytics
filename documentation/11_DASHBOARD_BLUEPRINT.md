# Dashboard Blueprint

## Page 1 — Executive Product Health
**Audience:** Product lead / leadership  
**Cards:** DAU, WAU, MAU, new registrations, task completion rate, net points issued, withdrawal success rate, data freshness.  
**Charts:** signup trend, active-user trend, task funnel, rewards and withdrawal trend.  
**Filters:** date range, platform, acquisition source, cohort.  
**Caution:** show metric definitions and last refresh time.

## Page 2 — User & Engagement
Activation funnel, cohort retention, DAU/MAU, repeat task participation, platform and acquisition segmentation.

## Page 3 — Tasks & Rewards
Task starts/completions/rejections, completion time, task category performance, points credited/reversed, reward issuance latency.

## Page 4 — Wallet & Withdrawals
Successful credits/debits, net movement, request volume, pending backlog, payout time, rejection/failure reasons. Restrict access to sensitive operational details.

## Page 5 — Referrals
Invites, attributed registrations, qualification, reward issuance and channel/campaign performance.

## Page 6 — Data Quality & Pipeline
Freshness by source, row volume, schema drift, missing IDs, duplicate rate, orphan rate, invalid status rate and failed pipeline runs.

## Global design rules
Use consistent timezone, approved metric definitions, explicit denominator labels, cohort eligibility notes, data freshness timestamp, role-based access and accessible labels.
