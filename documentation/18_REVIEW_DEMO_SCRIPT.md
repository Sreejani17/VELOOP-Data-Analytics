# Review Demo Script (5–7 minutes)

1. **Objective (30 sec):** Explain that this is a product analytics/data readiness blueprint.
2. **Evidence discipline (30 sec):** Explain simulated data and distinguish proposed features from confirmed facts.
3. **Coverage matrix (60 sec):** Show how product actions map to events and business questions.
4. **Event plan + dictionary (60 sec):** Explain event naming, required properties and field-level quality rules.
5. **KPI catalogue (60 sec):** Walk through task completion, reward issuance and withdrawal processing formulas.
6. **Profiling scripts (60 sec):** Run the sample profiler and explain that sample data is synthetic.
7. **Quality audit (60 sec):** Show intentionally messy records and how issues are detected/quarantined.
8. **Dashboard/pipeline (60 sec):** Explain the proposed architecture and dashboard pages.
9. **Limitations and next decisions (30 sec):** Ask for official data access and owner validation.

Do not claim that proposed events, pipelines, dashboards or product features are deployed.
